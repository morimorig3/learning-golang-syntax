# 基本データ型

## 整数

Goは符号付き整数算術と符号なし整数算術の両方を提供している

```
// 符号付き
int8 int16 int32 int64

// 符号なし
uint8 uint16 uint32 uint64
```

特定のプラットフォーム上の符号付き・符号なしに自然なサイズの型`int`と`uint`も提供している
プラットフォームによってコンパイラが判断するので基本的にこちらを使用すれば問題ない

実質は、32ビットか64ビットになる

### オーバーフロー

算術演算の結果型で表現可能なビット数よりも大きくなった場合黙って切り捨てられる

符号付きの場合はマイナスの結果になることもある

```
var i8 int8 = 127
var ui8 uint8 = 255
fmt.Println(i8, i8+1, i8*i8) // 127 -128 1
fmt.Println(ui8, ui8+1, ui8*ui8) // 255 0 1
```

### 整数通しの型変換

多くの場合は問題なく型変換可能

```
var i8 int8 = 1
var i int = int(i8)
fmt.Println(i) // 1
```

大きな整数を小さな整数に狭めたり、浮動小数点から整数またその逆をした場合精度を失う可能性がある

```
var f float64 = 3.14
fmt.Println(int(f)) // 3
f = 1.99
fmt.Println(int(f)) // 1 ゼロに近いほうに切り捨てる
```

### アドヴァーブ

`[n]`で第一オペランドを何度も使うように`Printf`に指示することができる

```
fmt.Printf("%[1]d1 %[1]d2 %[1]d3\n[1]で第一オペランドを何度も使うように指示できる", 10)
```
