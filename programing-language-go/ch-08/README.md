# ゴルーチンとチャネル

## ゴルーチン

Goでは並行に実行される個々の動作をゴルーチンと呼ぶ

プログラムが開始したとき、その唯一のゴルーチンはmain関数を呼び出すゴルーチンなので、そのゴルーチンをメインゴルーチンと呼ぶ

新たなゴルーチンは`go`文で生成される

```
go func()
```

予約語`go`が前につく普通の関数呼び出しあるいはメソッド呼び出し

`go`文によりその関数は新たに生成されたゴルーチンで呼び出される

## チャネル

チャネルはゴルーチン間の接続で、1つのゴルーチンから他のゴルーチンへ値を送ることができるようにする通信の仕組み

個々のチャネルはチャネルの要素型と呼ばれる特定の型の値のための導管

```
ch := make(chan int) // chはchan int型を持つ
```

チャネルは送信と受信という2つの主要な操作を持ちまとめて通信と呼ばれる

送信文は1つのゴルーチンから対応する受信式を実行している他のゴルーチンへチャネルを通して値を送信する

両方の操作は`<-`演算子を使用して書く

```
// 送信文
ch <- x

// 受信文
x = <-ch // 代入での受信
<-ch // 受信文: 結果は破棄する
```

チャネルはクローズすることができる

```
close(ch)
```

クローズするとこれ以上は送信されないことを示すことができ、その後に送信を試みるとパニックになる

閉じられたチャネルに対する受信操作は値がなくなるまで送信された値を生成する

値がなくなった後は受信操作を中止してチャネルの要素型のゼロ値を生成する

```
ch = make(chan int) // バッファなしチャネル
ch = make(chan int, 0) // バッファなしチャネル
ch = make(chan int, 3) // 容量3のバッファありチャネル
```

makeの単純な呼び出しで生成されるチャネルはバッファーなしチャネル
2つ目の引数であるチャネルの容量を整数で渡すことでバッファーありチャネルを生成することができる

## バッファーなしチャネル

バッファーなしチャネルへの送信操作は、別ゴルーチンが同じチャネル上で受信を実行するまで、送信しているゴルーチンを待たせる

```
x := 1
ch = make(chan int)
ch <- x // ここで止まる
```

バックグラウンドのゴルーチンはメインゴルーチンが終了したら閉じられる
たとえ、まだ動作していても

チャネルの目的がプログラムの同期である場合には要素が`struct{}`であるチャネルを利用する

```
done := make(chan struct{})
go func(){
    log.Print("done")
    <- struct{}{}
}()
<-done
```

## パイプライン

1つのゴルーチンの出力が別のゴルーチンの入力になるように複数のゴルーチンを接続するようにチャネルを使うことができる

チャネルの使用が終わったときにすべてのチャネルを閉じる必要はない
受信しているすべてのデータが送られたことを通知するのが重要な場合にチャネルを閉じる必要があるだけ

ガベージコレクターが到達不可能と判断したチャネルは閉じられているかどうかに関係なく回収していく

## 一方向チャネル型

関数`squarer`に渡される2つのチャネルは`out`が出力、`in`が入力を表しているが、これは命名で頑張っているだけで`out`を入力として使ってしまったりすることは構文的に可能になってしまっている

```
func squarer(out, in chan int) {
	for x := range in {
		out <- x
	}
	close(out)
}
```

この問題を防ぐためにGoでは一方向チャネル型が提供されている

`send-only`チャネル型（受信することができなくなる）

`chan<- int`

`receive-only`チャネル型（送信することができなくなる）

`<-chan int`

```
func squarer(out chan<- int, in <-chan int) {
	<-out // send onlyチャネルで受け取ろうとしているのでコンパイルエラー
	for x := range in {
		out <- x
	}
	close(out)
}
```

## バッファーありチャネル

バッファーありチャネルは要素のキューを持っている
キューのサイズはチャネル生成時に`make`に渡される引数によって決まる

3つの`string`値を持つバッファーありチャネルを生成する

`ch = make(chan string, 3)`

バッファーありチャネルへの送信操作はキューの最後に要素を追加する

```
ch := make(chan string, 3)
ch <- "A"
ch <- "B"
ch <- "C"
fmt.Println(<-ch) // A
fmt.Println(<-ch) // B
fmt.Println(<-ch) // C
```

いっぱいになって別ゴルーチンからも吐き出されない場合はデッドロックになる

```
ch := make(chan string, 3)
ch <- "A"
ch <- "B"
ch <- "C"
ch <- "D" // fatal error: all goroutines are asleep - deadlock!
fmt.Println(<-ch) // A
```
