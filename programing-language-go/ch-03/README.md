# 基本データ型

## 整数

Goは符号付き整数算術と符号なし整数算術の両方を提供している

```
// 符号付き
int8 int16 int32 int64

// 符号なし
uint8 uint16 uint32 uint64
```

特定のプラットフォーム上の符号付き・符号なしに自然なサイズの型`int`と`uint`も提供している
プラットフォームによってコンパイラが判断するので基本的にこちらを使用すれば問題ない

実質は、32ビットか64ビットになる

### オーバーフロー

算術演算の結果型で表現可能なビット数よりも大きくなった場合黙って切り捨てられる

符号付きの場合はマイナスの結果になることもある

```
var i8 int8 = 127
var ui8 uint8 = 255
fmt.Println(i8, i8+1, i8*i8) // 127 -128 1
fmt.Println(ui8, ui8+1, ui8*ui8) // 255 0 1
```

### 整数通しの型変換

多くの場合は問題なく型変換可能

```
var i8 int8 = 1
var i int = int(i8)
fmt.Println(i) // 1
```

大きな整数を小さな整数に狭めたり、浮動小数点から整数またその逆をした場合精度を失う可能性がある

```
var f float64 = 3.14
fmt.Println(int(f)) // 3
f = 1.99
fmt.Println(int(f)) // 1 ゼロに近いほうに切り捨てる
```

### アドヴァーブ

`[n]`で第一オペランドを何度も使うように`Printf`に指示することができる

```
fmt.Printf("%[1]d1 %[1]d2 %[1]d3\n[1]で第一オペランドを何度も使うように指示できる", 10)
```

### ショートサーキット

`&&`と`||`と組み合わせることができる

左オペランドですでに値が決定していれば、右オペランドは評価されない

```
// 空文字の場合右オペランドは評価されないので、s[0]はnullぽにならない
s != "" && s[0] == 'x'
```

## 文字列

文字列は不変なバイト列である

テキスト文字列は、UTF-8でエンコードされたUnicodeコードポイント（ルーン）の列である

`len`関数は文字列中のバイト数を返す（ルーンではない）

`s[i]`は文字列sのi番目のバイトを取り出す

```
s := "hello, world"
fmt.Println(len(s)) // 12
fmt.Println(s[0], s[7]) // 104 119
```

文字列は不変なので、新たな文字列の代入はできるが、文字列ないのバイト列は変更できない

```
s2 := "bright"
t2 := s2
s2 += ", brought"
fmt.Println(s2) // bright, brought
fmt.Println(t2) // bright

// s2[0] = 'L' コンパイルエラー
```

### 文字列リテラル

Goソースファイルは常にUTF-8でエンコードされるので、Goのテキスト文字列も慣習的にUTF-8として解釈される

ASCII制御コードを処理するエスケープがある

```
\a 
\b
\f
\n
\r
\t
\v
\'
\"
\\
```

### 生文字列リテラル

`"..."`ダブルクォートの代わりに``...``バッククォートを使用する

バックスラッシュと改行も含めて文字列になる

つまり、エスケープシーケンスは処理されない

```
rs := `ai\nueo` // ai\nueo
```

HTMLテンプレートやJSONリテラルなど、複数行に広がることが多いものに対して有用

### UTF-8

UTF-8は1から4バイトの可変長エンコーディングである

```
fmt.Println("世界") // 世界
// Unicodeコードポイントで文字を表すことができる
fmt.Println("\u4e16\u754c") // 世界
fmt.Println("\U00004e16\U0000754c") // 世界
```

UTF-8の特性のおかげで、文字列操作にデコードを必要としない

文字列に対してRangeループを使用する場合indexが飛ぶので注意しなければならない

```
// iは1ずつ繰り上がるわけではない
str := "Hello, 世界"
for i, _ := range str {
    fmt.Printf("%d\n",i)
}
0 1 2 3 4 5 6 7 10
```
