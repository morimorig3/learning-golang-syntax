# Goを選ぶ理由

開発者が楽しく開発できる言語だと感じた。
多くのユーザーに優しい言語だと感じた。
JavaやRubyなどそのほかの開発しやすい言語と比較して効率的であることもとても魅了的だ。

## 複数のプラットフォームで動作する

元々Webアプリケーションを作りたいという思いからプログラマの道へ進み出しました。そのときから、なぜ「Web」アプリケーションなのかの理由がブラウザさえ動けばどのようなプラットフォームからでも使えるものを作りたいと思ったからでした。

Goはどのようなプラットフォームでもシングルバイナリを実行すれば動かすことができる。動かせるべきであるという思想を感じ取れたのもGoを選ぶ理由のひとつです。

パフォーマンスが考慮されていることも1人のユーザーとしては見逃せないポイントでした。複数のプラットフォームで動いたとしても、たとえばモバイルだけとても動作が遅くて…というのはもうこりごりだなと感じていました。

## 開発のしやすさ

複数のプラットフォームで実行はもちろん開発ができることもGoを選ぶ理由のひとつでした。
それらは開発のしやすさを考慮することが根本思想にあるように感じ取れたので信頼を置けるポイントになっています。
ガベージコレクションを採用しているのも開発のしやすさやとっつきやすさにつながっていると感じました。

# チュートリアル

## 実行

goのコンパイル

```
$ go build .
```

バイナリファイルの実行

```
$ ch-01
```

コンパイルと実行をしてくれる

```
go run .
```

## パッケージ宣言の直前のコメント

パッケージ宣言の直前にパッケージの説明をコメントとして記述する慣例がある

```
// Echo1は、そのコマンドライン引数を表示する
package main
```

## 使われない変数は許されない

goでは使われないローカル変数は許されない

ブランク識別子（`_` アンダースコア）を使用する

```
// _ はindexが入るが使用しないので、_を使用する
for _, arg := range os.Args[1:] {}
```

## 文字列の連結は`+=`より`strings.Join()`を使用する

+=は毎度新しい文字列を生成するため非効率

```
func main(){
    fmt.Println(strings.Join(os.Args[1:]))
}
```

## Printfのヴァーブ

```
fmt.Printf("%d", 100)
```

| 表記 | 説明 |
|:---:|:---:|
|%d|10進数の整数|
|%x, %o, %b|16進数,8進数,2進数の整数|
|%f, %g, %e|浮動小数点数|
|%t|ブーリアン|
|%c|ルーン|
|%s|文字列|
|%q|文字列"abc"、あるいはルーン'c'|
|%v|任意の値に対する自然なフォーマット|
|%T|任意の値の型|
|%%|パーセント記号そのもの|

## 関数の宣言順序

関数とほかのパッケージレベルのエンティティはどのような順序で宣言しても構わない

```
func main() {
    countLines()
}

func countLines() {
}
```

## import

複数のパッケージのインポートは`()`で囲む

```
import (
    "image"
    "image/color"
)
```

パスで区切られたパッケージは最後の要素で参照する

```
import "image/color"

const white = color.White
```

## const宣言

コンパイル時に値が確定しているものは`const`で宣言する

値は数値・文字列・ブーリアンでなければならない

```
const size = 100
const (
    cycles = 5
    size   = 100
)
```

## コンポジットリテラル

以下のようなものはコンポジットリテラルと呼ばれる（構造体をリテラル表記で生成する文？）

`...`要素の並びからGoのコンポジット型インスタンスを生成する

```
[]color.Color{...} // スライス
gif.GIF{...} // 構造体
```

## 構造体

`gif.GIF型`は構造体と呼ばれる

構造体は異なる型を持つフィールドの集まりであり、ひとつの単一オブジェクトにまとめられたもの

```
gif.GIF{LoopCount: frames}
```

## ゴルーチン

Goでは関数の並列実行をゴルーチンと呼ぶ

`go`をつけて関数を呼び出す

ゴルーチンはチャネルとセットで使用する

チャネルはゴルーチンが特定の型の値をほかのゴルーチンへ渡すことを可能にする通信機構

```
ch := make(chan string)
go fetch(url, ch)
```
